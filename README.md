Хичээл: CS101 Алгоритм программчлалын үндэс (Flowgorithm → C) 
Багш: Д.Оюундэлгэр 
Хэлбэр: Хувиар гүйцэтгэх, оюутан бүр өөр даалгавартай
1. Зорилго
Хичээлийн агуулгыг (алгоритм, блок схем, хувьсагч, оролт/гаралт, нөхцөл, давталт, массив, функц, тэмдэгт мөр) нэг бүтэн жижиг програм дээр нэгтгэн хэрэглэх. Оюутан бодлогыг өөрөө шинжилж, Flowgorithm-д алгоритмаа зурж, C хэл дээр програмчилж, шалгаж, хамгаална.
2. Даалгавар хуваарилах дүрэм
Оюутан бүр өөрийн ангийн нэрсийн жагсаалтын дугаар (№)-аар даалгавраа авна. Ингэснээр оюутанд адил даалгавар давхардаж таарахгүй.
Юуг тодорхойлох вэ	Томьёо
Сэдвийн дугаар	((№ − 1) mod 30) + 1 → доорх 30 сэдвээс
Массивын урт N	6 + (№ mod 5)
Босго утга K	10 + №
Тусгай тэмдэгт / түлхүүр	№ -ийн сүүлийн орон

Жишээ: №7 оюутан → 7-р сэдэв, N = 8, K = 17. №37 оюутан → мөн 7-р сэдэв боловч N = 8, K = 47 гэсэн өөр параметртэй тул өгөгдөл, хариу нь өөр болно.
Сэдэв дотор "N", "K" гэж орсон хэсгийг өөрийн утгаар сольж ойлгоно.
